# Portrait Asset Directory

This directory hosts Anita's personal photography assets.

## Files
- `anita-portrait-placeholder.svg`: High-craft architectural placeholder SVG (used until the actual photograph is supplied).
- `anita-portrait.jpg` / `anita-portrait.png`: Drop Anita's actual photograph here.

## Recommended Specifications
- **Aspect Ratio**: 4:5 vertical editorial portrait (e.g., 1200 × 1500 px or 800 × 1000 px).
- **Background**: Neutral, moody, or dark backdrop to harmoniously integrate with the dark charcoal `#070809` canvas.
- **Lighting**: Cinematic side-lighting or soft studio portraiture.
